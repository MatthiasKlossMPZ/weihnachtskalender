Admin – Inhalte pflegen

Wähle einen Tag und bearbeite den Inhalt. Änderungen werden lokal im Browser gespeichert.
Für GitHub Pages: Lege Medien (Fotos/Videos) in einen Ordner media/ neben die HTML-Datei und trage relative Pfade ein (z. B. media/tag5.jpg). Data-URLs funktionieren lokal, sind aber für das Repo unpraktisch.

Tipp: Bilder werden lokal als Data-URL gespeichert (begrenzt durch Browser-Speicher, ca. 5 MB gesamt). Für GitHub besser eine relative URL (z. B. media/tag1.jpg) verwenden und die Datei ins Repo legen.
